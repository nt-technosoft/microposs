# WGT-007 / Receivable Summary Card

## Purpose
Показать клиентскую задолженность как понятную operational summary, а не как непрозрачное число.

## Used in screens
- customers / receivables
- checkout confirmation / customer detail contexts

## Required behavior
- show current outstanding
- show trend/recent activity if available
- provide drill-down entry point
- highlight overdue/problem states clearly

## Accessibility and UX
- amount must be readable in tabular numeric style
- status should not depend on color only
- card should support compact mobile layout
