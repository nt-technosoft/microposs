# Component Specifications

Документируются только shared и крупные domain widgets, которые влияют на UX-consistency или критические сценарии.

## Recommended component spec template
- `Widget ID`
- `Purpose`
- `Used in screens`
- `Props / inputs`
- `Outputs / events`
- `States`
- `Validation / constraints`
- `Accessibility`
- `Mobile behavior`
- `Desktop behavior`
- `Acceptance notes`

## Priority widgets
- bottom navigation
- floating cart
- select / dropdown patterns
- payment block
- procurement partner block
- balance status card
- ledger timeline
- receivable summary card
- empty / error / toast / confirm patterns
