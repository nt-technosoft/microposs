# WGT-009 / Stock Summary Card

## Purpose
Компактно показать stock/lot state по складу или товару.

## Used in screens
- lots and stock
- receiving queue / procurement detail secondary summaries
- dashboard alerts

## Required behavior
- show warehouse / lot identity
- show quantity remaining
- show status flags (active, depleted, low stock, etc.)
- support tap-through to detail

## Mobile behavior
- compact card, not row-heavy table
- highest priority fields visible without expansion
