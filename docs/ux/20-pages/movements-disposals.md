# SCN-WHS-005 / Movements and Disposals

## Route
- `/stock/movements` or `/stock/disposals`

## Roles
- warehouse
- owner

## Goal
Дать прозрачный журнал движения/списания товара и быстрый доступ к operational root-cause review.

## Primary actions
- inspect stock movement history
- inspect disposal reasons
- filter by warehouse/lot/date if needed

## UX note
Это журнал, а не primary action screen. На mobile должен оставаться читаемым через cards/timelines, а не только таблично.
