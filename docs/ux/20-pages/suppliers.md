# SCN-OWN-008 / Suppliers

## Route
- `/suppliers`

## Roles
- owner

## Goal
Вести справочник поставщиков и видеть payables/операционные обязательства без перегрузки finance hub.

## Primary actions
- search supplier
- create supplier
- inspect payable state
- register supplier payment

## Key sections
- supplier list
- payable summary
- payment action block
- create/edit bottom sheet or form

## Critical note
Это owner-only operational admin screen; не должен смешиваться с procurement create flow, но должен быть с ним легко связан.
