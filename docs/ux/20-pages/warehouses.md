# SCN-OWN-009 / Warehouses

## Route
- `/warehouses` or nested operational config route

## Roles
- owner

## Goal
Управлять справочником складов и видеть, какие из них участвуют в sales / receiving / stock flows.

## Primary actions
- list warehouses
- create / edit warehouse
- activate / deactivate warehouse
- inspect operational role of warehouse

## Key sections
- warehouse list
- status/activity indicator
- create/edit action

## Critical note
This is configuration/admin surface, not a high-frequency operational screen.
