# Page Specifications

Каждый экран оформляется отдельным файлом.

## Recommended page spec template
- `Screen ID`
- `Route`
- `Roles`
- `Goal`
- `Primary actions`
- `Secondary actions`
- `Entry points`
- `Exit points`
- `Sections / widgets`
- `States` (`loading / empty / error / success / forbidden`)
- `Functional requirements`
- `Non-functional requirements`
- `API / store dependencies`
- `Open questions / decisions`
- `Acceptance criteria`

## Naming
Использовать стабильные идентификаторы:
- `SCN-` for screens
- `WGT-` for widgets
- `FR-` for functional requirements
- `NFR-` for non-functional requirements
- `ACC-` for acceptance criteria
