# SCN-OWN-001R / Reports Dashboard

## Route
- `/reports`

## Roles
- owner

## Goal
Дать owner сжатую картину бизнеса по продажам, долгу, payables, cash flow и inventory, не подменяя собой полноценный dashboard/finance hub.

## Primary actions
- переключить период
- открыть reconciliation
- просмотреть top debtors / payables / inventory summary

## Risks / open question
Нужно решить границу между owner dashboard и reports dashboard, чтобы не плодить дублирование смыслов.
