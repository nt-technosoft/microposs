# Роли и Матрица Доступа

## Роли пользователей

| Роль | Назначение | Начальная страница |
|---|---|---|
| `platform_admin` | Суперадмин платформы; одобряет регистрации бизнеса | `/platform/requests` |
| `owner` | Владелец бизнеса; полный доступ к своему тенанту | `/sales` |
| `cashier` | Кассир; только продажи и касса | `/sales` |
| `warehouse` | Складской работник; приёмка и инвентаризация | `/procurements` |
| `investor` | Инвестор-партнёр; просмотр своих вложений и прибыли | `/investor/dashboard` |

## Специальные режимы

### simpleSellerMode (owner / cashier)
Включается в настройках. При активации:
- Навигация ограничена только `/sales`
- Router-guard перенаправляет с любых других маршрутов на `/sales`
- Подходит для простых торговых точек без нужды в аналитике

### Investor Layout
Инвесторы видят специальный layout (`meta.layout = 'investor'`) без основной навигации бизнес-модулей.

## API-уровень доступа

### `IsOwner` permission
Проверяет что пользователь является владельцем или сотрудником тенанта. Большинство business-эндпоинтов.

### `IsInvestor` permission
Проверяет что пользователь — активный инвестор (через `BusinessInvestorRelation.ACTIVE`). Используется на:
- `/api/v1/finance/fx-rates/` (list, retrieve, latest)
- `/api/v1/investors/` эндпоинтах

### `IsPlatformAdmin` permission
Только для `/api/v1/platform/` эндпоинтов (регистрации бизнеса).

## BusinessInvestorRelation

Связь между бизнесом и инвестором. Контролирует доступ к партнёрству.

| Статус | Значение |
|---|---|
| `PENDING` | Приглашение отправлено, не принято |
| `ACTIVE` | Инвестор активно участвует |
| `REVOKED` | Доступ отозван |
| `BLOCKED` | Заблокирован |

Только `ACTIVE` инвесторы могут участвовать в закупках (проверяется в `_validate_contract_payload`).

## Invite-система для инвесторов

1. Владелец создаёт `InvestorInvite` → уникальный токен + `expires_at`
2. Инвестор переходит по ссылке → принимает invite → его аккаунт привязывается к бизнесу
3. `BusinessInvestorRelation.status → ACTIVE`
4. Инвестор получает роль `investor` для этого тенанта
