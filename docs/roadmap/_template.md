# E0X — Название эпика

> Шаблон для новых эпиков. При создании нового файла — скопируй этот, переименуй и заполняй разделы. Не оставляй пустых разделов с заглушками — лучше удали.

**Статус:** `NOT_STARTED` | `IN_PROGRESS` | `IN_REVIEW` | `DONE` | `PAUSED`
**Прогресс:** N%
**Зависит от:** —
**Блокирует:** —

---

## Цель

1-2 предложения. Зачем нужен этот эпик бизнесу/продукту. Без расплывчатости.

## Контекст и обоснование

Откуда взялось требование. Если есть исходная сессия обсуждения — ссылка/дата. Какую боль решаем. Чем плохо то, как сейчас.
